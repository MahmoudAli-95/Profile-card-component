# 👤 Profile Card Component 🌐

> A sleek, responsive profile card component built with standard **HTML5** & **CSS3**[cite: 35, 36]. Features decorative SVG background patterns, overlapping avatar image styling, and key user statistics[cite: 35, 36].

---

### ✨ Features & Highlights

* 🖼️ **Overlapping Profile Avatar:** Centered circular image styled with a white border overlapping the header background[cite: 35, 36].
* 🎨 **Vibrant Background Styling:** Dark cyan primary background theme (`#19a2ae`) accented with dual positioned SVG circle background patterns[cite: 35, 36].
* 👤 **User Information Display:** Clear layout showing profile name, age badge, and location details.
* 📊 **Social Engagement Metrics:** Bottom stats section displaying total Followers (80K), Likes (803K), and Photos (1.4K)[cite: 35].
* 📱 **Fully Responsive:** Uses absolute background positioning and Flexbox alignment to adapt across mobile and desktop screens[cite: 36].

---

### 🛠️ Tech Stack

* 🌐 **HTML5:** Semantic markup structure using `main`, `section`, and list wrappers[cite: 35].
* 🎨 **CSS3:** Flexbox, CSS variables, absolute positioning, and smooth shadows[cite: 36].
* 🔤 **Typography:** Powered by Google Fonts (*Kumbh Sans*)[cite: 36].
